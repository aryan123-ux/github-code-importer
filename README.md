# Api Sentinel

Create a premium, hyper-futuristic full-stack SaaS application for "API Sentinel" from scratch using React, Tailwind CSS (Dark Mode), and modern UI components.

Generate the application with these specific features integrated into a clean, working single-page architecture:

1. "Futuristic Dashboard UI": A premium dark mode screen (slate-950) featuring a grid for monitored APIs (Stripe, OpenAI, Twilio, AWS) with glowing neon-green status pulses.

2. "Live Matrix Terminal View": A glowing black terminal window (bg-black, text-emerald-400) that automatically streams animated logs simulating real-time background API changelog web-scraping.

3. "GitHub Webhook & AI Layer": A visual simulation component showing how a failed GitHub workflow is parsed, sent to Claude 3.5 Sonnet, and automatically generates a "Shield Verified" hotfix Pull Request.

4. "Stripe Billing & Auth Portal": Modern subscription cards showing a "$499/mo Pro Plan" and an "$899/mo Enterprise Plan". Include a working GitHub Login simulation button and a simulated "Manage Subscription" dashboard card.

Ensure absolute high visual polish with smooth animations to give it a luxury $499/month infrastructure software feel.
